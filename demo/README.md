# Demos

Each folder is one demo: a `manifest.json` naming its trust anchor, its trusted witnesses, the time it is checked as of,
and its documents, in the order that tells the story of the network.

- `qa/` — one recorded run of the C# examples A1 to A13 of [WWCP_POI](https://github.com/OpenChargingCloud/WWCP_POI) at
  commit `801bbce`, public documents only, copied by `tools/vendor-qa-demo.mjs` from the test vectors of
  [WWCP_POI.TS](https://github.com/OpenChargingCloud/WWCP_POI.TS) (`tests/vectors/csharp-801bbce`), which vendors them from
  [WWCPPOIConformanceTests](https://github.com/OpenChargingCloud/WWCPPOIConformanceTests). Never edit them: they are signed.
- `thuringia/` — generated by `tools/generate-demo-network.mjs`, signed with test keys of fixed seeds. Run the generator
  again rather than editing them.
